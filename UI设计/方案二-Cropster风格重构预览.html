方案二：Cropster 风格重构 — 「Roasting Intelligence 轻量智能」

本方案完整借鉴 Cropster Roasting Intelligence（RI4/RI5）的工作流式轻量设计：以「烘焙前 → 烘焙中 → 烘焙后」三个阶段组织界面， 图表区最大化、按钮最少化；曲线数值集中在可折叠侧栏；底部调制阶段图（Modulation Chart）与阶段计时； 点击图表任意处弹出备注框；智能预测（豆温/RoR 未来 2 分钟、一爆预测、Flick 预警）； 流媒体式的底部 Start/Stop 大按钮；两栏式烘焙前准备布局与批次间隔计时器。 视觉风格采用 Cropster 的浅色、大圆角卡片、留白充足、品牌绿点缀的现代 Web 质感。
借鉴 Cropster RI 的关键特性： ① 三阶段工作流（Pre-Roast 两栏布局 / Roasting / After-Roast）② 右侧可折叠测量侧栏（Detachable Sidebar + 测量重排）③ 点击图表添加备注/事件（click-to-comment）④ 底部调制阶段图 + 阶段计时器（Modulation Chart）⑤ 智能预测开关（Smart Predictions：曲线预测/一爆预测/Flick 预警）⑥ 流媒体式 Start/Stop（RI4）⑦ Between Batch Timer 批次间隔计时 ⑧ 参考曲线 + 历史参考备注清理（Hide past reference comments）⑨ 结束时重量/备注编辑与保存流程 ⑩ 偏好设置中心（齿轮入口、分页）⑪ 曲线数值精确探查（RI5 Discover Curves' Values）⑫ Roast Compare Report 对比报告
