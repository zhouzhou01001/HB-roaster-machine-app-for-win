> **文档用途**：本文件为结构化设计指令，可直接作为 AI 输入，用于生成完整、一致的 UI 设计方案。
> 输出时须严格遵循以下每一项条目，不得自行增删功能模块、不得改变数据结构或业务逻辑。
> 本文档仅约束**界面呈现层**（样式、布局、视觉元素、交互反馈），不涉及任何后端逻辑。

## 1. 项目概述

### 1.1 产品类型
桌面端专业咖啡烘焙控制与记录软件（PySide6 / Qt 桌面应用，单机本地运行）。

### 1.2 目标用户
- 熟练咖啡烘焙师 / 烘焙工坊操作员。
- 需要在烘焙过程中实时监控温度曲线、记录关键事件、事后复盘分析批次质量。
- 技术水平：熟悉专业烘焙术语（豆温 BT、风温 ET、RoR、回温点 TP、一爆/二爆等），能接受较高信息密度界面。

### 1.3 核心功能（全量保留，不得删减）
| 模块 | 功能点 |
|---|---|
| 实时曲线图表 | 12 条曲线（IT/ET/BT/背景参考/三路 RoR/RoR 预测/燃气压力 mbar/风门档位/转速档位）；左轴温度、右轴 RoR 双轴；网格、缩放、里程碑预测线、事件竖线标注 |
| LCD 指标读数带 | 豆温、风温、时间、RoR、发展期 DTR、回温点 TP、进风温（CH3）、排风温（CH4）—— 顶部 LCD 式呈现 |
| 烘焙事件控制 | 8 类事件按钮：CHARGE / TP / YELLOW / FC_START / FC_END / SC_START / SC_END / DROP；三态：待录（虚线）→ 已录（琥珀）→ DROP 锁定（红色）；支持撤销重录 |
| 机台手动操作（仅记录） | 燃气压力（mbar，0–50，步进 0.5）、风门开度（第 1–10 档，独立）、滚筒转速（第 1–10 档，独立）；**纯手动设备，无任何自动控制逻辑，软件仅记录操作、不发送控制指令** |
| 里程碑 ETA 预测 | 转黄点 / 一爆开始预测时间 |
| 采集连接 | 串口设备连接（HB 三协议：Model S 四路 / TC4 / 旧三路），CH1–CH4 通道映射，断线自动重连，SIMULATION 模拟源 |
| 曲线对比 | 多批次曲线叠加比对，曲线库管理 |
| 回放 | 烘焙回放（倍速、滑杆定位、双图回放） |
| 批次分析 | 曲率 AUC、发展期指标、采样质量门、批次信息，导出 CSV/JSON/txt/PDF |
| 设置 | 坐标轴设置、显示设置（曲线可见性/线宽/主题）、调试日志与诊断包 |
| 数据存储 | SQLite 本地批次数据库 |
| 主题 | 深色 / 浅色双主题切换 |

### 1.4 设计目标
- **专业工作站感**：参考 Artisan 的"一屏掌控全部参数"理念，信息密度高但层次清晰。
- **操作直观**：高频操作（事件记录、参数调节）路径最短，支持键盘快捷键。
- **数据可读**：所有数值采用等宽字体 + tabular-nums 对齐，LCD 仪器铭牌质感。
- **纯记录语义**：界面不得出现任何暗示自动控制/程序自动/自动保持的措辞或控件。

## 2. 设计原则

1. **功能完整性优先**：所有现有功能必须保留，UI 优化不得删减或遗漏任何功能点。每屏须标注对应原模块（徽标 `原：XXX`）。
2. **一致性**：同类组件在所有页面使用完全相同的样式、尺寸、间距与交互反馈；颜色一律走设计令牌，禁止硬编码。
3. **层次清晰**：三级视觉层次 —— 背景 → 面板 → LCD/图表（最深）；通过投影、描边、底色递进区分。
4. **信息密度与留白平衡**：专业用户接受高密度，但需以 4px 网格节奏组织间距，避免拥挤。
5. **可访问性**：对比度达 WCAG AA（正文 ≥ 4.5:1，大字 ≥ 3:1），键盘可全程操作，焦点可见。
6. **响应式**：桌面端为主，支持平板适配（详见断点）；移动端不作为本期目标但布局可降级。
7. **纯呈现层约束**：本阶段仅修改样式/布局/视觉，不得改动功能逻辑、数据结构、业务流程、JS 行为。
8. **主题统一**：深色与浅色两套主题共用同一布局结构与组件，仅通过 CSS 变量换值实现配色切换，布局不得因主题不同而偏移。

## 4. 布局与栅格

### 4.1 栅格系统
- 基础网格单位 **4px**，所有间距为 4 的倍数（4 / 8 / 12 / 16 / 20 / 24）。
- 工作区三栏布局：左栏 `132px` 固定 + 中栏 `flex:1` 自适应 + 右栏 `236px` 固定；栏间 gap `10px`。
- 双列网格 `grid-template-columns:1fr 1fr; gap:10px`。

### 4.2 常用间距
| 场景 | 值 |
|---|---|
| 页面外边距 | `12px 14px 20px` |
| 栏间距 | `10px` |
| 面板内边距 | `12px` |
| 面板标题到内容 | `9px`（标题底部 `border-bottom` 后） |
| 组件块间距 | `10–13px` |
| LCD 卡片间距 | `8px` |
| 按钮内边距 | `5px 13px`（导航）/ `4px 11px`（步进） |

### 4.3 内容区域
- 桌面端最大宽度无硬上限，随窗口自适应；最小可用宽度 `1020px`。
- 图表区为视觉核心，占据中栏全部宽度，高度自适应（建议 `min-height:340px`）。

### 4.4 响应式断点
| 断点 | 宽度 | 行为 |
|---|---|---|
| 桌面（默认） | ≥1280px | 三栏完整布局 |
| 平板宽屏 | 1024–1279px | 右栏收窄至 `200px`，左栏保持 |
| 平板 | 768–1023px | 三栏降为单列纵向堆叠（左/右栏变全宽面板） |
| 移动 | <768px | 不作为本期目标；保证内容可滚动不溢出即可 |

## 5. 组件规范

> 每个组件须严格按以下规范实现，状态齐全，跨页面一致。

### 5.1 按钮（Button）
- **常规按钮**：`padding:5px 13px`；圆角 `--radius-s`；底色 `--btn`；文字 `--txt`；边框 `1px solid --line`；`transition: --t-fast`。
- **hover**：底色 `--btn-h`；边框转 `--accent`；上浮 `translateY(-1px)`。
- **active/按下**：`translateY(0)` 回落；底色 `--accent-dim`。
- **disabled**：`opacity:.45`；`cursor:not-allowed`；去掉 hover 变换。
- **主按钮（ON/START 等生命周期）**：常态即带语义色（ON=绿 `--ok`、START=琥珀 `--accent`、OFF=灰、RESET=灰）；激活态加 `box-shadow`。
- **事件按钮三态**：
  - 待录：`border:1px dashed --line`；文字 `--dim`。
  - 已录：`background:linear-gradient(180deg,rgba(240,168,63,.22),rgba(240,168,63,.12))`；边框 `--accent`；文字 `--lcd-on`；右上角发光圆点指示灯。
  - DROP 锁定：`background` 红 `--danger` 渐变；不可再点。
- **步进按钮（±）**：等宽字体；`padding:4px 11px`；hover 上浮 1px。

### 5.2 输入框 / 滑块（Slider）
- **滑块轨道**：`height:6px;border-radius:3px;background:--track`。
- **thumb（WebKit）**：`16×16px` 圆形；`border:2.5px solid --panel`；`box-shadow:0 1px 4px rgba(0,0,0,.45)`；`transition:transform .1s`；hover `scale(1.15)`。
- **燃气压力滑块**：0–50 mbar，步进 0.5，thumb 琥珀色 `--accent`；旁附 LCD 等宽读数 `18.5 mbar`；±0.5 步进按钮。
- **风门档位滑块**：1–10 档，thumb 青色 `#3fb6c9`；下方刻度尺 `1 2 3 … 10`（等宽 `--faint`）；读数 `第 N 档`。
- **转速档位滑块**：同风门结构，thumb 紫色 `#9d7bdc`；与风门完全独立。
- **禁用态**：`opacity:.5`；`cursor:not-allowed`。
- 滑块值变化须实时更新读数；调整后写入操作记录（仅记录，不发指令）。

### 5.3 卡片 / 面板（Panel）
- `background:--panel`；`border:1px solid --line`；`border-radius:--radius`；`padding:12px`；`box-shadow:--shadow`。
- 标题 H3：底部 `1px solid --line-soft` 分割；`padding-bottom:7px`；`margin-bottom:9px`；颜色 `--accent`；字距 `.8px`。
- 标题右侧挂 `原：XXX` 徽标（badge）。

### 5.4 LCD 数字读数卡（LCD）
- `background:linear-gradient(180deg,#1b1c21 0%,--lcd-bg 100%)`；`border:1px solid #000`；`border-radius:--radius-s`；`padding:8px 12px`；`min-width:106px`；`box-shadow:inset 0 1px 0 rgba(255,255,255,.05),--shadow`。
- 标签 `.lab`：`10px`、大写、字距 `1.5px`、色 `#8b877c`。
- 数值 `.val`：等宽、`23px`、`700`、右对齐、`text-shadow:0 0 12px`（发光）、`tabular-nums`。
- 副标 `.sub`：`10px`、右对齐、色 `#5f5c54`。
- 类目配色：ET 青、RoR 紫、时间 绿、进风温 `#5ba8e0`、排风温 `#e89b5a`，各配对应 `text-shadow`。
- hover：`translateY(-1px)`。

### 5.5 弹窗 / 对话框（Dialog）
- 以模态覆盖层呈现；背景 `rgba(0,0,0,.5)` 遮罩。
- 弹窗体同面板样式，`max-width:520px`，居中，`border-radius:--radius`。
- 标题区 + 内容区 + 底部按钮行（右对齐：取消 / 确定）。
- 支持 ESC 关闭、Tab 焦点_trap。

### 5.6 导航栏（TopNav）
- `display:flex;align-items:center;gap:5px`；底色 `--panel`；`border:1px solid --line`；`border-radius:--radius`；`padding:7px 12px`。
- Logo：`--accent` 色、`700`、前缀竖条 `3×14px`。
- 导航按钮：常态透明 `--dim`；hover `--panel2` 底 + `--txt` 文字；激活 `.on` = `--accent` 底 + 深色文字 `#231a08` + `box-shadow`。
- 菜单项 `.mitem`：`padding:3px 9px`；hover `--panel2`；分隔符 `.msep` 用 `--line` 色。

### 5.7 表单（Form）
- 标签 + 控件纵向排列；标签 `11.5px`、`600`、`--dim`。
- 复选框 `accent-color:--accent`；下拉框/选择框同按钮圆角。
- 表单分组用面板嵌套，组间 `gap:10px`。

### 5.8 状态提示（Toast）
- 右下角浮层；`background:--panel2`；`border:1px solid --accent`；`border-radius:--radius-s`；`padding:10px 14px`。
- 入场动画：`translateY(20px)→0` + `opacity 0→1`，`0.2s ease`；3s 后自动消失。
- 状态栏连接指示灯：常态呼吸动效（`opacity` 循环）；已连接绿 `--ok`；断线红 `--danger`。

### 5.9 表格（Table）
- 取消全框线，改圆角分区线 + 行 hover。
- 表头 `--dim`、`11.5px`、大写；单元格 `12px`；行 hover `--panel2` 底。
- 圆角 `--radius-s`；首尾行圆角承接容器。

### 5.10 图表容器（Chart）
- `background:--lcd-bg`（最深底）；`border-radius:--radius`；`border:1px solid #000`；`box-shadow:--shadow`。
- 网格线弱化（`--line-soft`）；曲线按 3.2 曲线色；图例可逐条开关（复选框）。

## 6. 页面结构

> 共 6 屏，每屏均挂「原：XXX」徽标便于逐项核对。以下按烘焙工作流优先级排序。

### 屏 1 · 烘焙主屏（最高优先级）
**信息架构（自上而下）：**
1. 顶部导航栏（Logo + 屏切换按钮 + 主题切换 ☀/🌙）
2. 菜单栏（文件/设备/视图/工具/帮助，对应原 21 项工具栏动作入口）
3. **LCD 数字读数带**（8 卡）：ET 风温 / BT 豆温 / RoR / 时间 / 回温点 TP / 发展期 DTR / 进风温（CH3）/ 排风温（CH4）+ 电源按钮组（ON/START/OFF/RESET）
4. 三栏工作区：
   - **左栏（132px）**：机台手动操作面板 —— 燃气压力 mbar 滑块 + 风门档位滑块 + 转速档位滑块 + 「仅记录」提示框
   - **中栏（flex）**：大图表（双轴曲线 + 里程碑预测虚线 + 事件竖线标注）+ 底部事件按钮条（8 类）
   - **右栏（236px）**：曲线图例（12 条可开关）/ 背景参考曲线 / 目标面板 / 报警面板 / 操作记录列表
5. 状态栏（连接状态指示灯 + 采样率 + 协议 + 主题）

**对应原模块**：MainWindow + CurveWidget + EventPanel + ActionPanel + TargetPanel + 采集连接逻辑

### 屏 2 · 采集连接
- 设备协议选择（HB Model S / TC4 / 旧三路）、端口/波特率、CH1–CH4 通道映射表、连接状态四态（未连接/连接中/已连接/断线重连）、SIMULATION 模拟源开关。
- **对应原模块**：serial_manager + hb_parser + channel_mapping

### 屏 3 · 设计 / 对比模式
- 背景参考曲线加载与偏差实时显示、多批次曲线叠加比对、曲线库列表（加载/删除/归档）、对比指标表（峰温/RoR 峰值/发展期比）。

## 7. 交互与动效

### 7.1 页面跳转
- 屏间切换为单页应用式 `display:none/block` 切换，无整页刷新；切换时保留各屏状态。

### 7.2 反馈动画
| 动效 | 时长 | 缓动 | 场景 |
|---|---|---|---|
| 按钮 hover 上浮 | `.14s` | `ease` | 所有按钮 |

## 8. 可访问性

1. **对比度**：正文 `--txt` 对 `--bg` ≥ 4.5:1；次级 `--dim` ≥ 3:1；LCD 数字对 LCD 底 ≥ 7:1。浅色主题下 `--dim:#78756d` 对 `#eceae4` 须验证 ≥ 4.5:1。
2. **键盘导航**：所有交互控件 `tabindex` 可达；`Enter/Space` 触发；事件按钮支持单字母快捷键；弹窗内焦点 trap + ESC 关闭。
3. **焦点可见**：`:focus-visible` 统一 `outline:2px solid --accent; outline-offset:2px; border-radius:4px`。
4. **屏幕阅读器**：LCD 数值卡用 `aria-label`（如 `aria-label="豆温 152.8 摄氏度"`）；事件按钮 `aria-pressed` 反映已录/待录态；图表提供 `role="img"` + 文字摘要 `aria-label`。
5. **不用纯颜色传达信息**：事件三态除颜色外辅以边框样式（虚线/实线/发光圆点）+ 文字标签。
6. **运动敏感**：呼吸灯/入场动画通过 `prefers-reduced-motion:reduce` 降级为静态或瞬切。
7. **滚动条**：自定义 `--btn` 色 thumb + `--bg` 透明 track，宽 `10px`，hover 加深。
