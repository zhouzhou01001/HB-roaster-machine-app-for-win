⑦ 差异点清单（按严重度）以代码与设计文档对照为准

① 顶部 UI 三层叠加 HIGH · main_window.py L154–373

同时存在 QMenuBar（文件/设备/视图/工具/帮助）+ QToolBar（开始监测/结束监测/...+ 3 个下拉）+ 新 TopNav（HB ROAST + 6 tab）。同一动作（如"连接设备"）在工具栏 act_connect 与导航 act_connect 中重复出现，违反单入口原则。

→ 建议保留 TopNav 为唯一顶部入口；QMenuBar 隐藏或转下拉；QToolBar 中"开始/结束监测"语义由 TopNav 旁的 ON/START/OFF 按钮承担

② 事件按钮 2×4 网格，违背"8 列横向" HIGH · event_panel.py L67 / L101–112

代码默认 grid.addWidget(..., index // 2, index % 2) 即 2 列布局；虽提供 set_button_columns 但仅在短屏触发。Artisan 与设计文档均要求底部 8 列横条（一眼可见所有事件）。

→ 建议中栏底部添加独立 event_strip 容器，固定 8 列；事件卡片仅保留备注/列表

③ 图表控制栏 12 个控件，过载 HIGH · main_window.py L629–734

「曲线显示」与右栏"曲线图例"功能重复；「线宽」与「单曲线线宽」职责重叠；「时间范围」spin + "应用范围"按钮挤占横向空间。设计文档要求图表内嵌工具栏 ≤ 5 项 + 目标摘要。

→ 建议移除"曲线显示"下拉（已由右栏图例 checkbox 承担）、合并线宽为单下拉、保留 RoR 窗口/自动跟随/轴/PDF

④ LCD 卡中文占位文字破坏等宽节奏 MID · 截图 B 区 / main_window.py L504–511

发展期 DTR 主标显示"等待一爆"5 个汉字；其余卡用"--.-"占位。设计文档要求数值位永远等宽数字或"-.--"。

→ 将"等待一爆/等待数据"等移至副标行；主标固定为数字或占位符

⑤ ON/START/OFF/RESET 嵌入 LCD 带最右，权重被稀释 MID · main_window.py L515–536

电源按钮组与 LCD 共用一行 8 卡布局，最右 4 列变成按钮，导致 LCD 被压成 4+4 不均。设计文档期望电源按钮组独占右上角 4 列（与读数带分离）。

→ 电源按钮组移出 LCD 带，单独一行右对齐（或在 TopNav 右侧）

⑥ 操作记录位置与目标预测混叠 MID · main_window.py L453–481

右栏右栏三层：曲线图例（4:2:0 拉伸）+ 目标与预测 + 采样状态。"操作记录"被设计文档要求单列，截图也未明显呈现手动操作记录卡。

→ 右栏改为：曲线图例 / 目标与预测 / 操作记录 / 采样状态 四卡，或按设计文档四层

⑦ 入风温 CH3 在主标题写"环境温 ET" LOW · main_window.py L504

代码注释/命名中 metric_et 实际显示为"环境温 ET"，但 CH3 是 IT（入风温），命名混淆。设计文档与最终 LCD 卡都希望"进风温 CH3"。

→ 命名/标签统一为"进风温 CH3"（IT）与"排风温 CH4"（Exhaust）

⑧ 里程碑 ETA 预测未在主屏突出 LOW · target_panel.py L20–28

目前放在右栏"目标与预测"中，标题"里程碑 ETA 预测"被小号字号淡化。设计文档希望转黄/一爆 ETA 在图表内（虚线 + 气泡）即时可见。

→ 在图表右侧加 ETA 气泡（实时倒计时），右栏仅保留目标温度设置
