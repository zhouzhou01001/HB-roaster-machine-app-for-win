# 周周 ROAST V1.0.1

本版在 V1.0 基础上发布 CH340 温度回传修复，不改变冻结架构。

## 修复

HB Model S 的部分固件不返回 CHAN 通道选择确认。现在允许无确认时继续 READ，同时保留完整温度帧、两组通道、有限数值及显式错误校验。不修改已确认的温度通道映射，不补造数据。

诊断过程见 [Model S 采集修复记录](../Model-S采集修复-2026-09-13.md)。

## 使用

关闭旧程序后解压运行新版 EXE。无需安装 Python 或 VS Code；串口驱动仍需安装。选择实际设备 COM 口、115200 波特率和 HB_MODEL_S 协议。本次真机端口为 COM3，不保证其他电脑端口相同。

用户数据继续使用原有用户数据目录。先开始采集，确认温度，再开始烘焙、入豆。授权码功能尚未实现。

## 验收与边界

本版本必须重新通过全量测试及 EXE 主窗口、曲线就绪和持续启动检查后发布。历史 V1.0 短时真机采集已成功，不代表 V1.0.1 已完成连续两锅或长期稳定性验证。
