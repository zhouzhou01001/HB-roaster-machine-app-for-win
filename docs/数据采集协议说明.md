# 温度数据采集协议说明

## 设备识别边界

- USB 串口列表显示设备描述、厂商、VID/PID，并把 `CH340`、`CH341`、`CP210x`/`Silicon Labs` 作为识别提示。
- 识别提示不是芯片鉴定结论。当前资料确认的是旧版 Silicon Labs CP210x 和新版 USB-SERIAL CH340；不把 CH431 当作已确认芯片。
- 用户必须在连接对话框中选择端口、协议 profile 和波特率。程序不会因为连接失败而切换模拟数据，也不会自动试探另一个波特率。

## 支持的 profile

### `HB_TC4`

- 支持波特率：`115200`、`9600`、`19200`；界面默认预选 `115200`，需要用户确认。
- 四路映射默认是 `CH1 -> ET（热风出风/出风温）`、`CH2 -> IT（热风进风/进风温）`、`CH3 -> BT（豆温）`、`CH4 -> WORK（设备工作/环境温）`。
- 接收四路文本帧后才进入样本链路；缺失 `CH1` 到 `CH4` 的帧会被拒绝。

### `HB_LEGACY_3`

- 用于旧三路配置，兼容已有三路通道映射和旧数据。
- 可选择 `9600`、`115200` 或 `19200`，实际连接的波特率会写入样本证据。

## 帧格式和时间语义

- JSON：`{"CH1": ..., "CH2": ..., "CH3": ..., "CH4": ...}`，可选 `time_s` 和 `unit: "C"`。
- 键值：`CH1:...,CH2:...,CH3:...,CH4:...` 或 `IT:...,ET:...,BT:...`。
- `HB_TC4` 数字帧：四个数表示 `CH1..CH4`，五个数表示 `time_s,CH1..CH4`。
- `HB_LEGACY_3` 数字帧：三个数表示 `CH1..CH3`，四个数表示 `time_s,CH1..CH3`。
- 温度单位固定按摄氏度 `C` 解释；声明其它单位的帧拒绝。
- 没有设备时间戳时使用采集线程的相对时间；有设备 `time_s` 时记录为设备时间。样本保存 `time_basis`。
- 半帧、无换行帧、乱码、`READ`/`CHAN` 回显和不支持格式不会写入样本，并增加可见解析异常计数。

## 命令边界

`READ` 和 `CHAN;1300` 只在 `HB_TC4` 或 `HB_LEGACY_3` profile 下发送。未知 profile 直接拒绝连接；`SIMULATION` 不发送设备命令。

## 数据可追溯字段

每条实时样本保存 `source`/`data_source`、端口、实际波特率、协议 profile、完整 `raw_frame`、`parser_format`、温度单位、时间基准、采集前解析异常数和通道映射签名。`SIMULATION` 只能由用户在采集源对话框中明确选择，样本来源标记为 `SIMULATION`。

## 资料依据

- HB 官方《HB-Coffee Roaster 烘焙记录软件 2.0 安装说明》：USB 设备识别提示、旧版/新版连接说明和波特率范围。
- Artisan 官方仓库：[artisan-roaster-scope/artisan](https://github.com/artisan-roaster-scope/artisan)。
- Artisan TC4 资料：`READ` 命令、四路温度语义和摄氏模式。具体设备仍以用户选择的 profile、端口和波特率为准，不盲猜硬件型号。
