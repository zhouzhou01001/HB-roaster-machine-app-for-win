# 周周 ROAST V1.0 交付说明

本次基于当前最新源码构建，版本保持 V1.0，未回退程序。适用于 Windows x86-64；目标电脑无需安装 Python 或 VS Code。USB 串口驱动仍需由设备使用者安装。

## 本次曲线界面变更

本次为 V1.0 的 Qt 启动修复重建版，交付文件名带 `qtfix` 标识。原无修复标识的 V1.0 包已报告 QtCore 加载失败，请使用本次重建包。

构建已排除误从 Poppler 收集的 `icuuc.dll`，由 Windows 系统提供 Qt 所需的 ICU。启动验收必须收到主界面与曲线区域可见的事件循环确认，再持续运行至少 10 秒；仅错误弹窗或进程存活不能通过。

- 左侧豆温、环境温、进风温、排风温、烘焙时间、发展期六项参数单列显示，为曲线让出横向空间。
- 精简重复标题，窄屏事件按钮使用单行文字，温度与 RoR 曲线菜单提供分组和彩色线型标识。
- 空间不足时自动减少坐标数字标签，保留用户设定的轴范围、主刻度间隔和网格位置。
- 保留非负坐标、滚轮禁用和左键拖动；未修改温度采集协议、通道映射、RoR 算法或烘焙状态机。

## 使用与数据

本次重建还包含锅次恢复修复：保存失败会在确认窗口显示原因，可重试且不会重复归档；没有正式采样的空锅需明确确认取消，才会清除临时事件并返回采集状态，不生成虚假记录。设备断线时仍禁止开始新锅，恢复有效温度后才恢复按钮。正常连续烘焙无需重复连接设备。

解压后运行 `04-可执行程序/烘焙软件-1.0.exe`。先选择真实串口并开始采集，确认温度反馈，再开始烘焙；点击入豆后才开始正式计时和记录。模拟模式仅用于演示，不代表设备读数。升级前请备份原有烘焙档案与配置。

## 构建与验证边界

开发环境安装 `requirements-build.txt` 和 `requirements-dev.txt` 的锁定依赖后，执行 `python scripts/build_exe.py --smoke-exe`，再执行 `python scripts/assemble_delivery.py`。以包内本次报告为准，不引用历史测试数量作为本次通过依据。

离屏界面检查、自动化测试及 EXE 启动检查不能替代真实 HB Model S 长时间连接和连续烘焙试用。本次不会宣称完成未实际执行的硬件验证。旧版设计文档仍为原冻结记录，后续架构或功能设计变更需按用户审批要求执行。
