# HB Model S 采集修复（2026-09-13）

## 原因与修改

真机在 COM3、115200 波特率下，对 `CHAN;1200` 和 `CHAN;3400` 不返回确认，但后续 `READ` 正常返回温度。旧逻辑要求完整确认，否则提前结束读取，最终报告无温度反馈。

现允许 CHAN 无响应时继续 READ；显式错误、残缺确认、残缺温度帧及非有限温度仍拒绝。仅两组 READ 都有效时才产生一条采样，保持原通道映射，不产生模拟或补造数据。

## 真机证据

- 接口：Windows 识别为 USB-SERIAL CH340（COM3）。
- 参数：115200，HB_MODEL_S。
- 修复前：0 条有效采样，10 次确认错误，随后超时。
- 修复后：约 8 秒内收到 6 组真实采样，0 次解析错误，无连接错误。
- 原始返回：`27.0,30.1,29.4,C` 与 `27.0,29.8,0.0,C`。
- 对应豆温 29.8℃、环境温 0℃、进风温 29.4℃、出风温 30.1℃。环境温 0℃是设备原始值，不是软件补值。

## 测试范围

增加无 CHAN 确认的真机帧回归，以及第二组 READ 缺失、半帧、错误、非有限值的拒绝回归。既有显式确认与错误响应测试继续保留。
