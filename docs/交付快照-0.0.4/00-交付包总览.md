# 烘焙软件 0.0.4 交付包总览

## 1. 交付身份

- 产品：烘焙软件
- 发布版本：`0.0.4`
- 冻结架构基线：`0.0.3-r1`
- 构建标识、组装时间与哈希：见 `06-校验/release-metadata.json`
- 已验证平台：Windows 11 x86-64；本交付包不声明 Windows 10、Windows ARM64 或其他系统已获认证

## 2. 发布结论与限制

本版本满足当前自动化测试与交付包完整性检查，可用于 Windows 11 x86-64 环境下的安装前验收和 HB Model S 实机验证。它不是“长期硬件稳定性已完全证明”的声明：真实设备长时间连续烘焙、不同 USB/串口芯片批次、断线重连和现场电气干扰仍需实机耐久测试。

交付建议状态：**满足文档及自动化验证条件，建议有条件通过**。这不是项目所有者的正式批准；最终批准以项目所有者签署或明确确认的验收记录为准。自动化测试失败、源码绑定不一致、冻结基线复制校验失败、ZIP CRC 失败或 SHA-256 不匹配均阻断交付；现场耐久测试属于生产使用认证前必须关闭的验证项。

## 6. 验证方式

1. 阅读 `06-校验/release-metadata.json`，确认版本、平台和制品路径。
2. 用同目录外部 `.sha256` 文件核对完整交付 ZIP。
3. 解压后按 `06-校验/SHA256SUMS.txt` 核对包内文件。
4. 阅读 `06-校验/test-report-0.0.4.json`，确认 `status=PASS`、失败数为 0、错误数为 0，并检查跳过数。
5. 确认测试报告的 `application_source_sha256` 与 `release-metadata.json` 一致。
6. 确认 `frozen-baseline-verification.json` 为 `PASS`。

## 7. 已知问题与非交付范围

- 未完成跨多台 HB Model S、不同 USB 转串口批次的长时间耐久认证。
- 未认证 Windows 10、Windows ARM64、macOS 或 Linux。
- 未包含 USB-COM 驱动安装包。现场设备被用户称为 CH431，最终芯片型号、驱动名称和版本必须以 Windows Hardware ID 与设备供应方资料为准。
- 未承诺旧于当前文档所列格式的任意第三方烘焙文件都可无损导入。
- 不提供云同步、多人协同、远程设备控制或数据库服务器。

## 10. 实机耐久认证门槛

生产使用认证前，由项目所有者指定的设备测试责任人与现场操作员共同完成：连续采集不少于 8 小时、连续完成不少于 3 个完整烘焙批次，并分别在采集阶段和烘焙阶段执行一次主动断线/恢复。验收要求：程序不崩溃、不产生重复采集线程或重复批次；不以 0℃ 或插值补造缺失温度；缺失区间可识别；端口恢复后在 3 个配置采样周期内恢复真实数据；温区映射与设备面板一致；3 个批次均可重新载入并导出 PDF。

任一条件失败时，停止“生产环境稳定”认证，保留本版为实验室受限使用，登记缺陷和设备/驱动/日志证据，修复并完成回归后重新执行整套耐久测试；不得用改写历史批次或伪造缺失数据的方式通过验收。责任与状态在 `01-当前版本文档-0.0.4/04-改善事项报告.md` 的 `RISK-001` 持续跟踪。
