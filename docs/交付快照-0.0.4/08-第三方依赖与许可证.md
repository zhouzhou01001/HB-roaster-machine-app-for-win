# 第三方依赖与许可证说明

本程序使用 Python、PySide6、pyqtgraph、pyserial、NumPy、pandas、PyInstaller 等第三方组件。交付包 `06-校验/dependency-versions.txt` 从实际组装环境的包元数据生成准确版本和许可证字段，优先于本文的概括描述。

| 组件 | 用途 | 许可证核对要求 |
|---|---|---|
| Python | 运行时 | 以对应 Python 版本官方许可证为准 |
| PySide6 / Qt | 桌面 UI | 必须按实际采用的 Qt/PySide 授权方案履行 LGPL/GPL 或商业许可要求 |
| pyqtgraph | 曲线绘制 | 以安装包元数据和上游 LICENSE 为准 |
| pyserial | 串口通信 | 以安装包元数据和上游 LICENSE 为准 |
| NumPy / pandas | 数据计算与处理 | 以安装包元数据和上游 LICENSE 为准 |
| PyInstaller | 单文件构建 | 以对应版本许可证及引导加载器例外条款为准 |

商业发布前由发布责任人核对交付中实际包含的全部依赖、许可证文本、版权声明和源码提供义务。本文不是法律意见，也不以概括性名称替代许可证原文。升级依赖后必须重新生成依赖报告并重新评估授权义务。
