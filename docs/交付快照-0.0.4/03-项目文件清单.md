# 周周 ROAST 0.0.4 项目文件清单

## 1. 整理后目录

```text
hb/
├─ app/                 应用源码
├─ config/              仓库配置样例
├─ data/                默认数据库
├─ dist/                仅保留当前 EXE
├─ docs/                协议、维护、冻结基线和当前交付快照
├─ release/             冻结基线包与 0.0.4 完整交付包
├─ scripts/             构建、诊断、探针与交付工具
├─ tests/               自动化测试
├─ UI设计/              产品/UI 文档、预览和 QA 截图
├─ main.py              程序入口
├─ README.md            项目入口说明
├─ TESTING.md           测试与发布门槛
├─ PROJECT_TASKS.md     当前状态与后续任务
├─ requirements.txt     Python 依赖
├─ pytest.ini           pytest 范围配置
├─ version_info.txt     Windows 版本资源
└─ 烘焙软件-0.0.4.spec 当前 PyInstaller 规格
```

## 2. 根文件

| 文件 | 用途 |
|---|---|
| `main.py` | Qt 程序入口、工作目录初始化和主窗口启动 |
| `README.md` | 当前版本、能力、运行、构建和目录说明 |
| `TESTING.md` | 自动化与真机验收清单 |
| `PROJECT_TASKS.md` | 当前完成状态和优先级队列 |
| `requirements.txt` | 运行与构建最低依赖 |
| `pytest.ini` | 限制 pytest 只收集项目测试 |
| `version_info.txt` | EXE 文件版本、产品版本和名称资源 |
| `烘焙软件-0.0.4.spec` | 当前 PyInstaller 生成规格 |

## 7. 已移除的冗余

- `build/` 全部 PyInstaller 中间文件。
- `outputs/` 全部历史重复 EXE。
- `dist/` 中除 `0.0.4` 外的历史 EXE。
- `UI设计/_analysis/` 旧 EXE 解包出的第三方运行库和反编译材料。
- `UI设计/` 根目录中的重复 EXE。
- 根目录旧 spec、Codex 运行日志、临时脚本和缓存。
- 所有 `__pycache__`、`.pyc` 和 `.pytest_cache`。

实际清理路径和释放空间记录在交付包 `06-校验/清理执行记录.md`。
