# 数据格式兼容与迁移

`.hbroast` 是基于 SQLite 的烘焙数据文件，当前数据库 Schema 版本为 4，包含时间序列、温度、ROR、事件、燃气、风门、滚筒转速和相关元数据。0.0.4 保证由当前版本保存的数据可由当前版本重新载入；不声明任意 Artisan 文件、第三方文件或未知旧版本变体可无损导入。

## 字段规则

- 正式时间从入豆 `00:00` 开始。
- 入豆前预热数据不写入正式批次曲线。
- 温度或 ROR 缺失必须保持缺失语义，不能用 0℃ 伪造。
- 用户控制没有变化时沿用上一条有效值。
- 未知事件和字段不得静默映射为其他含义。

## 兼容策略

| 输入 | 行为 |
|---|---|
| 当前版本完整文件 | 正常载入并验证关键字段 |
| 缺少非关键可选字段 | 使用明确缺省值，并在日志记录 |
| 缺少时间或核心温度字段 | 拒绝作为完整批次载入，提示原因 |
| 含未知字段 | 保留原文件；读取时忽略或记录，不覆盖原件 |
| 第三方/未知旧版本 | 先复制样本，单文件试迁移和人工核对，不批量覆盖 |

## 迁移流程

1. 对原文件做只读备份并计算 SHA-256。
2. 在副本上执行载入或转换。
3. 核对总时长、入豆点、排豆点、温度曲线、ROR、事件和控制档位。
4. 保存为新文件名，不覆盖源文件。
5. 重新载入新文件并导出 PDF 进行人工比对。
6. 只有样本全部通过后才批准批量迁移。

后续若调整数据结构，必须新增明确的格式版本字段、迁移函数、向后兼容测试和失败回滚策略，并取得用户对功能与设计文档变更的审批。
