# ROR 计算规范

## 统一定义

ROR 是最近时间窗口内温度对时间的局部线性回归斜率，时间单位为秒、温度单位为摄氏度，最终结果为 `斜率 × 60`，单位固定为 `°C/min`。

- 默认窗口：10 秒。
- 配置范围：1-60 秒。
- 通道：`it`、`et`、`bt`、`work`。其中 `work` 是当前数据模型中的第四温度通道，界面显示为出风温。
- 规范持久字段：`it_ror`、`et_ror`、`bt_ror`、`work_ror`。
- 底层保留浮点数；界面可以显示整数。
- 负 ROR 必须保留，不因图表显示下限为 0 而改写数据。

## 数据有效性

1. 四通道共用所有有限时间戳中的最大值作为窗口终点。
2. 窗口使用闭区间 `[终点-窗口, 终点]`。
3. 时间和温度必须可以转换为有限浮点数；`NaN`、`Inf`、空值和非法文本被忽略。
4. 相同时间戳只保留原输入顺序中最后一个有效值。
5. 每个通道至少需要 3 个唯一有效时间点。
6. 实际时间跨度至少为 `max(1秒, min(5秒, 窗口×0.5))`，否则返回 `None`。

## 回归权重

权重按样本在实际时间跨度中的位置计算，而不是按样本序号计算：

`alpha = 0.35 + 0.65 × (time - first_time) / actual_span`

回归采用明确的加权最小二乘公式。最新点目标权重为 1，最旧点为 0.35。该规则保留当前算法对新数据更敏感的意图，同时消除不等间隔采样下的点序权重歧义。

## 返回规则

- 数据不足、时间跨度不足或回归结果非有限时返回 `None`。
- 非法窗口直接抛出 `ValueError`，不静默改写参数。
- 有限但突变的温度不在 ROR 层静默删除或钳位；异常样本应由采集质量门禁处理或产生诊断信息。
- 入豆后正式样本历史重新开始；满足最低数据条件前正式 ROR 为 `None`，不得引用预热历史。

## 依据

本规则由本对话代码审查与独立 GPT 算法审查对齐后确定。Artisan 官方资料也将 Delta Span 作为按秒定义的 ROR 时间跨度，并建议常用 10-15 秒跨度；本程序保持默认 10 秒，同时对实时异常输入增加确定性保护。
