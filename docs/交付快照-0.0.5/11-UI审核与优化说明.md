# 0.0.5 UI 审核与优化说明

## 审核范围

- 主屏信息层级与曲线有效面积。
- 1280x720 与 1920x1080 响应式布局。
- 右上实时温度与 RoR 的完整显示。
- 事件按钮状态语义与深浅主题一致性。
- 无用或重复状态表达。

## 已实施结论

1. 右上指标区保持两列三行，不扩大右栏，不压缩曲线。
2. BT、ET、IT、XT 四张通道卡统一为“温度主读数 + 对应 RoR 副读数”。动态数值与静态单位分离，避免三位负值造成裁切。
3. RoR 副读数统一显示整数，单位统一为 `°C/min`。
4. 移除界面上独立的 `ΔBT` 重复卡，改为显示烘焙时间与发展期 DTR。
5. 指标标签使用完整的“BT 豆温 / ET 环境温 / IT 进风温 / XT 排风温”；重复的 CH 编号留在设备通道配置中，主屏不再占用实时读数宽度。
6. 事件按钮取消模块内硬编码主题色，统一继承主窗口深浅主题令牌。
7. 待记录事件使用中性虚线，已记录使用琥珀色；仅排豆锁定使用危险红色。
8. 主屏不显示“供电正常”或“预览中心”，设备状态仅由采集流程状态表达。

## 保持不变

- 未改变采集通信、烘焙状态机、事件记录、数据库、导出或曲线坐标逻辑。
- 未增加任何自动控制语义；燃气、风门和滚筒转速仍然只记录人工操作。
- 未修改冻结基线 `docs/框架冻结基线-0.0.3`。

## 发布验收

- 1280x720 下四个通道的温度和 RoR 不截断、不重叠。
- 边界值 `-123.4 °C` 与 `RoR -123 °C/min` 的数值和静态单位均完整可见。
- 1920x1080 及更高分辨率下曲线仍为主视觉区域。
- 深色与浅色主题的事件按钮状态一致。
- 入豆锁定保持琥珀语义，排豆锁定使用红色危险语义。
- 全量自动化测试、EXE 启动冒烟和交付包哈希绑定均通过后方可发布。
