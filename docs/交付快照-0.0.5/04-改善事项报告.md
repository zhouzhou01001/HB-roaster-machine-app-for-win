## 优先级

1. `RISK-001`：真实设备长时间与断线恢复验证。
2. `RISK-002`：部署目标扩展时建立操作系统矩阵。
3. `RISK-003`：形成现场串口检查记录。
4. `RISK-004`：收集历史文件样本后建立迁移测试集。

## 变更控制

冻结基线只描述 `0.0.3-r1` 架构。任何新增功能或模块依赖调整必须先提交变更说明、影响分析、测试计划并取得用户审批；风险状态变化可在当前版本交付快照中更新，但不得反向改写冻结材料。

## RISK-001 失败处置

耐久验收失败后立即暂停生产稳定性认证，保存设备 Hardware ID、驱动版本、串口配置、日志、批次文件和复现步骤，登记阻断缺陷。修复版本通过 139 项自动化回归、交付完整性校验和完整耐久测试后方可关闭风险；不允许通过删除失败记录、补造温度或缩短标准关闭风险。
